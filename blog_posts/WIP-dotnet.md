It's probably best to think of ".NET" as a brand that evolved over time. Just like Yamaha [began as a brand for musical instruments](https://en.wikipedia.org/wiki/Yamaha_Corporation) and later [expanded into a big name in the motorcycle industry](https://en.wikipedia.org/wiki/Yamaha_Motor_Company), .NET is a brand containing several products and has changed over time. 

It's a common misconception that .NET is an acronym, likely because it's often spelled using capital letters. In fact, ex-Microsofter [Justin Grant](https://stackoverflow.com/a/1495470) says that .NET was chosen as a nod to the stack's network-enabled selling point (and also as it was short, easy to spell and localise, approachable to non-technical business leaders, and not legally risky). He also points to a blogpost by James Kovac, an interesting read which is now available [via the Wayback Machine](https://web.archive.org/web/20071016051420/https://www.jameskovacs.com/blog/CNETHistoryLesson.aspx). So, the name doesn't tell us much. 

.NET began in 2000, when Microsoft announced the first version of the C# programming language, an alternative to Java. C# was transpiled into Common Intermediate Language (CIL - analogous to Java bytecode), which is then compiled to platform-specific code by the Common Language Runtime (CLR - the virtual machine layer that manages execution of .NET programs, like the JVM is to Java). They also released some core software libraries to support development, taking the burden off of the end user to implement and maintain common data structures and algorithms. Together, this stack is known as the .NET Framework, a powerful all-around set of tools which could be used to create web APIs, websites, Windows native apps, command line tools, and more. The set of tools to develop using .NET, including the CLR, compilers, and NuGet package manager, was collectively known as the .NET SDK (Software Development Kit). 

In 2014, Microsoft announced the .NET Core project, which unlike Framework was both open-source and cross-platform across Windows, macOS, and Linux. The full stack, including the standard libraries, compiler platform (codenamed Roslyn), and core CLR implementation was made open, and Microsoft founded the .NET Foundation to support the ecosystem. In 2020, with the release of .NET 5, the "Core" name was dropped from branding, so .NET 5 and onwards refer to the same open-source stack as .NET Core 1 through 3 (there was no .NET Core 4). This naming scheme continues to this day, with .NET 10 being the most recent SDK version and .NET 11 scheduled to release later this year. 

The .NET name has also been attached to other products, including web API and application framework ASP.NET (and later ASP.NET Core), Xamarin successor .NET MAUI, database library ADO.NET, and more. Generally, the .NET branding indicates that a project is part of the .NET ecosystem. 

Since its initial release, the .NET stack has become progressively more versatile, faster, and more open. As well as C#, .NET now fully supports F# (a functional language designed for .NET), VB.NET (a variant of Visual Basic) and C++/CLI (a variant of C++, though it is not a first class citizen on macOS and Linux), with limited support having existed for other languages in the past. It remains most popular within the enterprise sector as a competitor to Java, with startups, students, and others still preferring the likes of the Python or JavaScript ecosystems, but with its ever-increasing openness, it continues to become an increasingly competitive option for a variety of use cases. 

TL;DR: .NET began as Microsoft's proprietary Windows-only code platform, and evolved into a diverse open-source and cross-platform ecosystem.
